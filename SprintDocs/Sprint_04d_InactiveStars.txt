SPRINT 04D - INACTIVE STARS ON THE LEVEL-COMPLETE PANEL
Project: Find The Cheeky Monkey (working title: Monkey Rush)
Engine: Unity 6000.3.6f1

GOAL
Stars that were not earned should show the grey inactive_star image
instead of a blank slot. A loss shows 3 grey stars. A 2-star win shows
2 gold stars and 1 grey star.

CAUSE
- Sprint 04c filled starObjects in JungleMap and BeachMap. Since then,
  UpdateStars hides the stars that were not earned (SetActive false).
- Before 04c the field was empty there, so the panel always showed 3 gold
  stars, even for a 1-star win or a loss.
- Assets/Art/UI & UX/inactive_star.png was never used in any scene,
  including at HEAD and in git history.

DESIGN DECISIONS
- Idea from the developer: place an inactive star at the exact position
  of each gold star, behind it. When the code hides a gold star, the grey
  one shows.
- No code change. UpdateStars already does the hiding.
- The inactive stars are siblings in StarGroup, placed directly before
  each gold star, so UI draws them first (behind). StarGroup has no
  layout group, so extra siblings do not move anything.
- The inactive stars are not in starObjects, so the code never hides
  them.
- Each inactive star is a copy of its gold star: same RectTransform,
  CanvasRenderer and Image values. Only the sprite differs.
- Creating new objects is outside the standing scene-edit rules. The
  developer approved this directly in chat. The edit was made by a script
  in the scratchpad, after a dry run with safety checks.
