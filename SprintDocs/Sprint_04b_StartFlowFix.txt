SPRINT 04B - START FLOW FIX
Project: Find The Cheeky Monkey (working title: Monkey Rush)
Engine: Unity 6000.3.6f1

GOAL
After main-menu Play, and after panel Restart or Next, the level must start
on its own with 3-2-1-GO and the monkey walk. Before this sprint it only
started after pressing Start in the pause menu. Snow's panel Restart
already worked.

CAUSE (confirmed by reading the code and the scene wiring)
- MapWindowController.TryStartSelectedLevelWithCountdown reads the
  PlayerPrefs int "StartSelectedLevel". If it is not 1 it stops, and the
  monkey stays in Idle. It clears the flag to 0 just before the countdown.
- Only MenuWindowController.StartCurrentLevel and
  MapWindowController.SelectLevel set it to 1.
- MainMenuController.PlayGame, LevelCompletePanelController.
  RestartCurrentLevel and LevelCompletePanelController.LoadNextLevel did
  not set it.
- Scene wiring: panel Restart in JungleMap and BeachMap calls
  LevelCompletePanelController.RestartCurrentLevel. In SnowMap it calls
  MenuWindowController.RestartLevel, which is why Snow worked. Panel Next
  calls LevelCompletePanelController.LoadNextLevel in all three maps.
  The Sprint 04 failed panel reuses the Restart button as retry.

DESIGN DECISIONS
- Set the flag to 1 and save, right before the scene load, in the three
  methods that were missing it.
- Each file declares its own private const string StartSelectedLevelKey
  = "StartSelectedLevel", the same way MenuWindowController and
  MapWindowController already do. No shared helper.
- No core script, scene, prefab or Inspector change.
