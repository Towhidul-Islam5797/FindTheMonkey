SPRINT 02b - TIME BONUS POPUP
Project: Find The Cheeky Monkey (working title: Monkey Rush)
Engine: Unity 6000.3.6f1

GOAL
Show the time bonus on the level-complete panel as a short popup
sequence. The "Time bonus: +N" label appears, then the coin reward text
updates to include the bonus, then the label hides. Display only. The
bonus coins are already saved in Sprint 02.

DESIGN DECISIONS
- A first attempt used a flying "+N" text (TimeBonusFlyAnimation). It
  needed a second text object and extra wiring per scene, and it was not
  working in the scenes. It was replaced by a simple popup sequence that
  reuses the existing Time Bonus Text and Coin Reward Text.
- The sequence uses WaitForSecondsRealtime, because the panel sets
  Time.timeScale = 0.
- Order: wait show delay, show the label, wait hold, set the coin text to
  "+" followed by star coins plus bonus, wait hide delay, hide the label.
- The label is hidden when the panel is built. It is shown only when the
  bonus is greater than 0. With a bonus of 0 it never shows.
- The star, coin and time bonus calculation and its order are unchanged.
  The bonus still adds to coins only (LevelState.AddCoins), not score,
  bananas or stars.
- No new PlayerPrefs key. No existing key was renamed or removed.

CHANGES
- Edited: Assets/Scripts/LevelCompletePanelController.cs (only file)
  Added: using System.Collections.
  Added: Header "Time Bonus Popup" with bonusShowDelaySeconds (0.5),
  bonusHoldSeconds (1.0), bonusHideDelaySeconds (0.4), all [Min(0f)].
  Added: private field lastCoinReward, set before UpdatePanelUI.
  Added: PlayTimeBonusPopup() coroutine.
  Added: in ShowPanel, after OpenPanel() and UpdateButtonStates(),
  StartCoroutine(PlayTimeBonusPopup()) when lastTimeBonus > 0 and both
  timeBonusText and coinRewardText are assigned.
  Added: in UpdatePanelUI, the timeBonusText object is hidden after its
  text is set.
- The fly animation was added and then removed in this sprint:
  TimeBonusFlyAnimation.cs was created, then deleted by hand in Unity
  together with its .meta file and its scene components.
- No script other than LevelCompletePanelController.cs was changed in
  the final result.
