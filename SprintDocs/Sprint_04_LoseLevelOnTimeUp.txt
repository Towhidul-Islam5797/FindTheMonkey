SPRINT 04 - LOSE A LEVEL WHEN THE TIMER RUNS OUT
Project: Find The Cheeky Monkey (working title: Monkey Rush)
Engine: Unity 6000.3.6f1

GOAL
A level can now be lost when the timer reaches 0:00. The loss reuses the
existing level-complete panel. It is a per-level option, off by default.
A level without LevelSettings, or with the new checkbox off, behaves
exactly as before: at 0:00 the timer stays at 0:00 and play continues.

DESIGN DECISIONS
- New checkbox End Level When Time Runs Out on LevelSettings, default off.
- LevelTimer raises a new event, OnTimeUp, once, when the remaining time
  is 0 and the active LevelSettings has the checkbox on. IsTimeUp is
  reset in StartTimer() and StartTimerWhenMovementEnds().
- LevelCompletePanelController listens to OnTimeUp. HandleTimeUp() sets
  panelShown, disables every HidingObject component (this stops taps
  without editing HidingObject), shows the failed panel, then pauses the
  game the same way ShowPanel does.
- The failed panel shows: title "Level N Failed!", 0 stars, +0 for score,
  bananas and coins, the tries text and the time text as on a win, and no
  time bonus. The Next button is hidden. The existing Restart button stays
  active and is the retry. No new button, no new Inspector field.
- The loss path does not call CompleteCurrentLevel, MarkMonkeyFound,
  AddCoins or ClaimBonus, and saves nothing. A lost level never lowers a
  previous best, never unlocks the next level and never pays anything.
- The win path is unchanged: ShowPanel, UpdatePanelUI (including the
  "Level N Complete!" title), and the order of the star, coin and time
  bonus calculation.
- HandleTimeUp keeps the ResolveReferences and ValidateRequiredReferences
  guard before it sets panelShown, the same guard ShowPanel uses.
- Dropped from the first plan: an extra failedRetryButton field. The
  existing Restart button already calls the right method.

KNOWN ISSUES / NOTES
- The first test showed no failed panel because the checkbox was still
  off on that level. This is the intended default, not a bug.
- CLAUDE.md invariant 14 and section 2.4a say the timer never ends a
  level. That is now only true when the checkbox is off. Update CLAUDE.md
  by hand after the tests.
- If a wrong-tap slide is in progress at 0:00, HidingObject.OnDisable
  stops its coroutine and the object stays displaced behind the panel.
  Restart reloads the scene, so it should be harmless. Check during the
  tests.
- The failed panel only hides the star objects. Whether it shows empty
  stars depends on the panel in the scene. Grey background stars would be
  a scene or prefab change by hand.
- The controller subscribes to LevelTimer in OnEnable. If the LevelTimer
  does not exist yet at that moment, it is not subscribed. This is the
  same limit the file already has for LevelState.
- Win-path Restart and Next behaviour after a loss depends on the known
  debt "Start flag" in CLAUDE.md section 11. Verify the restart in Play
  mode.
- AGENTS.md shows as modified in git. It is written by Unity's AI
  Assistant and was not touched. Do not commit it.
- The assistant cannot run Unity. Only the SnowMap Level_3 result above
  was seen, and it was reported by the developer.
