STEPS (BY HAND, IN UNITY)
1. Assets/Audio/GameFeedbackManager.prefab: tick Vibration Enabled.
   Save.
2. Edit > Project Settings > Player > Android tab > Other Settings:
   - Package Name: com.tpstudio.monkeyrush
   - Version: 0.2.0
   - Bundle Version Code: 2
3. Assets > External Dependency Manager > Android Resolver > Force
   Resolve. Wait until it finishes without errors.
4. File > Build Profiles > Android:
   - Scene list as above.
   - Development Build: off.
   - Keystore: default debug keystore (Publishing Settings unchanged).
   - Build. File name: MonkeyRush_0.2.0_test.apk.
5. Install on one Android phone (adb install or copy the file) and run
   the device test in SprintDocs/Phase2_DeliveryChecklist.txt.
6. Commit the prefab and ProjectSettings changes (see the commit
   message below). Do not commit the APK.
