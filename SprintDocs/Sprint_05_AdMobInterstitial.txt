SPRINT 05 - ADMOB SETUP AND INTERSTITIAL AD (TEST IDS ONLY)
Project: Find The Cheeky Monkey (working title: Monkey Rush)
Engine: Unity 6000.3.6f1
Plugin: Google Mobile Ads Unity plugin 11.6.0 (installed by the developer)

GOAL
Show a test interstitial ad when the player taps Next on the
level-complete panel, every few levels, then continue to the next level.
If no ad is ready, or AdsManager is missing, Next works as before.
Ads are child-directed from the first build (kids' game, ages 5 and up).

DEVELOPER DECISIONS
- One new script, AdsManager, approved for this sprint.
- Four files approved (plus AdsManager.cs.meta created by Unity).
- No rewarded ad, no banner, no consent (UMP) code in this sprint.
- When the count is reached but no ad is ready, the count stays, so the
  next Next tries again.
- A second call while an ad is open is ignored. The first call's
  callback still runs once.
- Load retry: if no ad is loaded and no load is running, Next starts a
  new load and continues at once.

CHANGES
1. New: Assets/Scripts/AdsManager.cs
   - Singleton like GameFeedbackManager (Instance, DontDestroyOnLoad,
     duplicates destroyed).
   - Start (Android and iOS only): RaiseAdEventsOnUnityMainThread = true,
     RequestConfiguration with TagForChildDirectedTreatment.True and
     MaxAdContentRating.G, then MobileAds.Initialize, then the first
     interstitial load.
   - Inspector fields: androidInterstitialId, iosInterstitialId (Google
     test IDs as defaults), levelsBetweenInterstitials (default 3, Min 1),
     showDebugLogs.
   - ShowInterstitialThen(Action onFinished): counts calls (session only),
     shows the ad on the Nth call when CanShowAd() is true, otherwise
     calls onFinished at once. On close or show failure: destroy the ad,
     load a new one, call onFinished once.
   - isLoading flag for the retry. A newly loaded ad replaces and
     destroys any old ad object.
   - Debug.Log lines for load success, load failure, show, close and
     show failure.
2. LevelCompletePanelController.cs, LoadNextLevel only: the final
   mapLevelManager.LoadNextLevel() call now goes through
   AdsManager.Instance.ShowInterstitialThen when AdsManager exists.
   Restart, HandleTimeUp and the failed panel are unchanged.
3. CLAUDE.md: AdsManager in 2.3, new section 2.4c (ads), scope (10) and
   known debt (11) updated, including the iOS music note.
4. This file.
